# onclinical.github.io

Sitio web oficial de **onclinical** — *Eficacia y Seguridad bajo Prescripción*.

Publicado a través de GitHub Pages en: [https://onclinical.github.io](https://onclinical.github.io)

## Estructura

- `index.html`: Página de bienvenida ("En construcción") optimizada, responsive y con diseño clínico corporativo.
- `assets/logo.png`: Logotipo oficial en alta resolución y fondo transparente.
- `favicon.ico`, `favicon.png`: Favicons basados en el isotipo de la marca.
- `.nojekyll`: Archivo de configuración para GitHub Pages.
